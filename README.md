## The Patron Index
`Tagline: ` 
    Where Buyers become Insights
    Patrons that powers Business
    See beyond the Sale

`Problem Statement:`
    Businesses often have large amounts of customer purchase data but lack a simple way to understand which customers matter most and how their buying behavior changes over time.
    The Patron Index is a secure customer intelligence platform that analyzes purchase history and automatically classifies customers into meaningful segments such as High-Value, Loyal, Regular, At-Risk, and Inactive. It provides businesses with a clear dashboard to understand their customers, identify important trends, and make better marketing and retention decisions while keeping customer data secure.

`Tech Stack :`
    Frontend: React.js, Tailwind CSS, Chart.js
     Backend: Node.js, Express.js
    Database: MongoDB
    Machine Learning: Python, Scikit-learn, Pandas
    ML API: FastAPI
    Security: Malware Detection + File Validation
    Authentication: JWT, bcrypt
    Deployment: Vercel, Render
    Version Control: Git, GitHub
